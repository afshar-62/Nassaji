# بسته سورس‌کد نهایی پروژه پلتفرم تاروپود (Taropod)

این فایل به عنوان مانیفست تحویل سورس‌کدهای نهایی تا این لحظه صادر شده است.

---

## ۱. فایل‌های فشرده (ZIP) آماده دانلود
* **بسته سورس‌کد خالص (سبک و فوری):** `taropod-code-only.zip` (حجم: ۴۷۵ کیلوبایت)
* **بسته کامل با تمامی دارایی‌ها و ۳۳ تصویر گرافیکی:** `taropod-full-source.zip` (حجم: ۱۸.۷ مگابایت)
* **صفحه مستقل دانلود در سرور پلتفرم:** مسیر `/download` یا تب تنظیمات اپلیکیشن

---

## ۲. خلاصه بخش‌های فنی تکمیل‌شده در این نسخه
1. **سیستم کالیته ۵ رنگ برندینگ نساجی:**
   * مودال انتخاب پالت‌ها: `src/components/ColorPalettePickerModal.tsx`
   * موتور تنظیم متغیرهای CSS Tailwind v4: `src/utils/themePalette.ts`
   * اعمال تم انتخابی نارنجی آجری صنعتی روی تمامی دکمه‌ها، نشان‌ها و کامپوننت‌های UI
2. **معماری ماژولار سرور (Express):**
   * دایرکتوری `server/modules/` شامل:
     - `profiles/`: پروفایل کسب‌وکارها، پرسنل و مجوزها
     - `explore/`: فیدهای هوشمند الگوریتمی، استوری‌ها و دسته‌بندی
     - `listings/`: سامانه آگهی‌ها و نیازمندی‌های تخصصی
     - `businesses/` و `locations/`: نقشه جغرافیایی و موقعیت واحدها
     - `taxonomy/`: دسته‌بندی‌های ۱۱ گانه نساجی، خیاطی و پوشاک
3. **پایگاه داده (PostgreSQL + Drizzle ORM):**
   * `src/db/schema.ts` و مایگریشن‌های پوشه `drizzle/`
   * داده‌های سید ۲۰ کسب‌وکار فعال نساجی در `server/seed/textileMarketSeed.ts`
4. **رابط کاربری و کامپوننت‌های فرانت‌اند (React 19 + Tailwind v4):**
   * پلیر ویدیویی اختصاصی: `src/components/CustomMediaPlayer.tsx`
   * اکسپلورر بازارگاه: `src/components/ExploreMarket.tsx`
   * فید صفحه اصلی و استوری‌ها: `src/components/HomeFeed.tsx`
   * تب تنظیمات و دریافت مستقیم کدها: `src/components/SettingsView.tsx`

---

## ۳. دستورات اجرای پروژه روی سیستم شما
```bash
# نصب پکیج‌ها
npm install

# اجرای محیط توسعه
npm run dev

# ساخت و اجرای نسخه نهایی
npm run build
npm start
```
